RemoteHunt

RemoteHunt is a personal, self-hosted job-search assistant built and used by Parth Chaitanya. It runs only on its owner's own computer and is not offered to other users.

With the owner's permission it uses the Gmail API to read job-alert and recruiter emails in the owner's own mailbox, apply labels, save reply drafts (never sent automatically), and send a daily job digest to the owner's own address.
