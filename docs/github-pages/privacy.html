RemoteHunt Privacy Policy

Last updated: 28 September 2026

RemoteHunt is a personal job-search tool that runs on its owner's own computer. It is used only by its owner, Parth Chaitanya, and is not a public service.

Data accessed

With the owner's explicit consent through Google OAuth, RemoteHunt uses these Gmail API scopes:

  • gmail.modify: to read job-alert and recruiter emails, apply labels, and create draft replies.
  • gmail.send: only to send a daily job digest to the owner's own email address.

How data is used and stored

  • All data is stored locally on the owner's computer. Nothing is sold, shared, or sent to any third-party server operated by RemoteHunt.
  • OAuth tokens are stored encrypted.
  • RemoteHunt never sends email to anyone other than the owner. Replies to recruiters are saved only as drafts for the owner to review and send manually.
  • Short, anonymised text excerpts (with email addresses and phone numbers removed) may be sent to an AI model provider (Groq) to draft text, at the owner's request.
  • RemoteHunt's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from the app's "Disconnect Gmail" button or at myaccount.google.com/permissions. Disconnecting deletes the stored token.
